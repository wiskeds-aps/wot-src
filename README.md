# wot-src (fork)

Fork of [izeberg/wot-src](https://github.com/izeberg/wot-src) — the
decompiled World of Tanks client source, regenerated by izeberg's own bot
on every client update.

This branch (`automation`) is the fork's deliberate **default branch**. It
holds no game source itself, only the sync automation below — unlike the
branches carrying actual source, it is never force-reset, so the workflow
that depends on it can't be wiped out by its own sync run.

## Source branches

The decompiled client source lives on these branches, each kept as an
exact, force-synced mirror of the matching upstream branch — no local
commits, ever:

- `EU`, `NA`, `ASIA`, `CN`, `CT`, `PT_RU`, `RU`

Used locally as a reference when reverse-engineering/building WoT mods —
real API shapes (e.g. `gui/battle_control/avatar_getter.py` for what a
`BigWorld.player()`-returned avatar exposes), and ready-made stand-ins for
native engine modules under `_stubs/` (`zlib`, `cPickle`, `_heapq`, etc.).
Doesn't include `BigWorld` itself — that's a native engine binding with no
Python source, here or in the real client.

## Auto-sync

`.github/workflows/sync-upstream.yml` runs every 6 hours (and on manual
dispatch). For each source branch:

1. Hard-resets it to match upstream (`gh repo sync --force`).
2. If anything changed, opens a GitHub issue on this repo summarizing what
   changed — commit count, changed-file list, compare link — per branch.
